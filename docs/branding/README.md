# EasyFood: logo e iconos (originales; el icono Android está en androidApp/src/main/res)

Marca: una «E» hecha con una barra vertical y tres barras horizontales separadas (la del centro, más corta), como las barras de macros de la app. Rojo primary #FF4D4F sobre #0B0B0B, esquinas de 4 dp. Texto del logo: Sora convertido a trazos («Easy» en onSurface y «Food» en primary).

- logo/logo-oscuro.svg|png: para fondos oscuros, fondo transparente («Easy» #EDEDED, «Food» #FF4D4F). PNG a 2x (2222x720).
- logo/logo-claro.svg|png: para fondos claros («Easy» #0B0B0B, «Food» #C4161C).
- android/ic_launcher_foreground.svg|png: lienzo de 108 dp (PNG de 432x432, es decir, xxxhdpi), transparente. La marca ocupa x 32–76 e y 30–78, dentro de la zona segura (21–87).
- android/ic_launcher_background.svg|png: color liso #0B0B0B.
- android/ic_launcher_monochrome.svg|png: extra para los iconos temáticos de Android 13+ (<monochrome>).
- icono/icono.svg + icono-1024.png: icono principal a sangre, con la marca un 30 % más grande.
- ios/AppIcon.svg + AppIcon-1024.png: el mismo, 1024x1024, RGB sin alfa y sin esquinas redondeadas.
